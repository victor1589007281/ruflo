# APP & 小程序整合团队设计方案 (v2 — 跨团队协调)

> **版本**: 2.0 | **日期**: 2026-04-20
> **工作流名**: `app` / `miniprogram` / `mobile`
> **模式**: `app_composite` (自定义编排器)

---

## 一、设计理念

**不是独立团队，而是整合调度现有团队能力的跨团队协调器。**

| **阶段** | **复用团队** | **复用能力** |
|:--------:|:-----------:|:------------:|
| 需求分析 | **调研团队** (research) | fanout 并行调研 + 综合分析 |
| UI/UX 原型 | **创意团队** (creative-v2) | HTML原型 + AdaptiveTerminator 对抗审查 |
| 架构&研发 | **研发团队** (development) | architect/coder/tester/reviewer 角色 |
| 小程序适配 | **扩展** | 新增 `miniprogram-dev` 角色 |

## 三、复用的团队角色

| **角色** | **来源团队** | **在此工作流的职责** |
|:--------:|:-----------:|:-------------------:|
| synthesizer | 调研团队 | 需求规划、需求综合 |
| researcher | 调研团队 | 用户调研、技术调研 |
| creative-planner | 创意团队 | UI/UX策划 |
| html-developer | 创意团队 | HTML交互原型 |
| art-director | 创意团队 | 原型视觉审查 |
| architect | 研发团队 | 技术架构设计 |
| coder | 研发团队 | 前端+后端开发 |
| tester | 研发团队 | 集成测试 |
| reviewer | 研发团队 | 代码审查 |
| **miniprogram-dev** | **新增** | 小程序开发 |

## 四、新增角色

### `miniprogram-dev`
- 精通微信/支付宝小程序
- 熟悉 Taro 3.x / uni-app (Vue 3)
- 覆盖: 微信登录, 支付, 分享, 订阅消息
- 性能: 分包加载, setData 优化
