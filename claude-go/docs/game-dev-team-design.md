# 游戏研发整合团队设计方案 (v2 — 跨团队协调)

> **版本**: 2.0 | **日期**: 2026-04-20
> **工作流名**: `game` / `gamedev` / `game-dev`
> **模式**: `game_composite` (自定义编排器)

---

## 一、设计理念

**整合所有现有团队资源，构建全新的游戏团队。**

| **阶段** | **复用团队/引擎** | **复用能力** |
|:--------:|:----------------:|:------------:|
| 游戏设计 | 新增角色 | `game-designer` 产出 GDD |
| 剧情演化 | **群体智能引擎** (predict) | `swarm_intel.Engine.Simulate` + `Predict` |
| 美术原型 | **创意团队** (creative-v2) | HTML原型 + AdaptiveTerminator 对抗审查 |
| 引擎开发 | **扩展研发团队** | 新增 2D/3D 引擎专属角色 |
| 测试优化 | 新增游戏专属角色 | 可玩性+性能+兼容性 |

## 三、群体智能剧情演化 (Phase B)

参照 **novel-v3** 的 `swarm_intel.Engine` 集成模式:

1. **多线模拟** (`Engine.Simulate("social")`):
   - 主线剧情 (5 Agent, 3 轮)
   - 支线剧情 (4 Agent, 2 轮)
   - 隐藏剧情 (3 Agent, 2 轮)
   - 三线并行执行

2. **群体智能评估** (`Engine.Predict()`):
   - 多分析师辩论
   - 贝叶斯融合
   - 拜占庭修剪
   - 选出最佳剧情组合

## 四、新增游戏专属角色 (8个)

| **角色** | **职责** | **技能** |
|:--------:|:--------:|:--------:|
| `game-designer` | 核心机制/数值/叙事 | GDD文档、玩法循环、数值平衡 |
| `game-architect` | 引擎选型/架构设计 | Phaser/Three.js/Canvas/Pygame |
| `game-engine-dev` | 渲染/物理/音频/输入 | 游戏循环、碰撞检测、对象池 |
| `game-logic-dev` | 游戏机制/AI/状态机 | 状态机、行为树、战斗系统 |
| `level-designer` | 关卡数据/PCG/难度 | Wave Function Collapse、平衡 |
| `game-tester` | 功能/性能/平衡性 | 帧率测试、兼容性矩阵 |
| `game-optimizer` | 渲染/内存/包体优化 | 对象池、资源压缩、打包 |

## 五、游戏类型支持

| **类型** | **引擎/框架** | **适用场景** |
|:--------:|:------------:|:-----------:|
| 小游戏 | Canvas/Phaser.js/PixiJS | 微信小游戏、H5 |
| 2D游戏 | Phaser.js/Pygame/Kaboom.js | 休闲、像素风 |
| 3D游戏 | Three.js/Babylon.js | Web 3D |
| 跨平台 | Godot (GDScript) | 移动+PC |
