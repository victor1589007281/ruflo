# 育儿&教育顾问团队设计方案

> **版本**: 1.0 | **日期**: 2026-04-21
> **定位**: 覆盖婴儿到大学全阶段的专业育儿教育咨询平台

---

## 一、调研来源

| 领域 | 参考 | 核心启发 |
|:----:|:----:|:--------:|
| **AI 辅导** | Khanmigo(Khan Academy), Duolingo Max | 苏格拉底式引导, 自适应学习路径 |
| **发展心理学** | Piaget 认知发展, Erikson 社会发展, Vygotsky 最近发展区 | 分阶段策略 |
| **CBT 方法** | 认知行为疗法基本框架 | 情绪管理, 积极心理 |
| **学习科学** | 间隔重复, 交错学习, 主动回忆, 元认知 | 学习方法推荐 |
| **国内平台** | 作业帮, 学而思, 松鼠 Ai | 中国教育特色需求 |

---

## 二、设计原则

```
┌─────────────────────────────────────────────────────────────┐
│  P1: 全阶段覆盖 — 婴幼儿/学龄前/小学/中学/高中/大学           │
│  P2: 多维咨询 — 心理/学习/情感/能力培养/亲子关系               │
│  P3: 安全第一 — 危机识别 + 专业转介, 绝不替代心理医生           │
│  P4: 苏格拉底式引导 — 不直接给答案, 引导思考                   │
│  P5: 个性化 — 根据年龄/性格/学习风格定制建议                   │
└─────────────────────────────────────────────────────────────┘
```

---

## 三、工作流 DAG

```
Intake ──▶ SafetyScreen ──▶ DomainRouter ──┬──▶ AcademicTutor
                                            ├──▶ PsychologyCoach
                                            ├──▶ ParentingAdvisor
                                            └──▶ DevelopmentAssessor
                                                      │
                                                ActionPlan ──▶ FollowUpPlan ──▶ Report
```

### 阶段详解

| # | 阶段 | 角色 | 说明 |
|:-:|:-----|:-----|:-----|
| 1 | **Intake** | intake | 收集基本信息: 孩子年龄/阶段/问题描述 |
| 2 | **SafetyScreen** | safety | 危机筛查: 自伤/虐待/严重心理问题 → 转介专业机构 |
| 3 | **DomainRouter** | router | 智能路由: 学习问题/心理问题/亲子问题/发展评估 |
| 4 | **AcademicTutor** | tutor | 学科辅导: 苏格拉底式引导, 学习方法推荐 |
| 5 | **PsychologyCoach** | psychologist | 心理支持: CBT 框架, 情绪管理, 社交技能 |
| 6 | **ParentingAdvisor** | parent_coach | 家长指导: 教养方式, 沟通技巧, 家庭环境 |
| 7 | **DevelopmentAssessor** | assessor | 发展评估: 认知/语言/社交/运动里程碑 |
| 8 | **ActionPlan** | planner | 综合行动计划: 具体步骤 + 时间表 |
| 9 | **FollowUpPlan** | follow_up | 跟进计划: 复查节点 + 效果评估标准 |
| 10 | **Report** | reporter | 输出咨询报告 |

### 年龄阶段适配

| 阶段 | 年龄 | 重点领域 | 方法特点 |
|:----:|:----:|:--------:|:--------:|
| 婴儿期 | 0-1岁 | 依恋/感统/睡眠 | 家长指导为主 |
| 幼儿期 | 1-3岁 | 语言/社交/自理 | 游戏化, 家长协同 |
| 学龄前 | 3-6岁 | 入学准备/专注力/情绪 | 短时多元, 故事引导 |
| 小学 | 6-12岁 | 学习习惯/基础学科/社交 | 结构化方法, 激励系统 |
| 初中 | 12-15岁 | 学业压力/青春期/自主性 | 尊重隐私, 同伴视角 |
| 高中 | 15-18岁 | 高考/生涯规划/心理 | 目标导向, 压力管理 |
| 大学 | 18-22岁 | 自主学习/职业/人际 | 教练式对话, 反思 |

## 四、安全机制

```
用户输入 → 关键词检测 (自伤/暴力/虐待)
         → LLM 风险评估
         → 高风险 → 立即输出专业机构联系方式 + 停止咨询
         → 中风险 → 温和引导 + 建议寻求专业帮助
         → 低风险 → 正常咨询流程
```

---

## 五、编排引擎集成

- SafetyScreen 作为硬前置依赖, 阻塞下游
- 4 路领域专家并行 (根据路由器结果, 只激活相关路径 — 条件边)
- 会话记忆通过 Blackboard 持久化
- 全程检查点, 支持多轮咨询续接
